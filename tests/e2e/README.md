# End-to-End Tests (`tests/e2e`)

## Overview
This directory will house Playwright automated end-to-end (E2E) test suites validating full user flows across Next.js UI, Go API, and PostgreSQL.

## Status
* **Milestone 0**: Blueprint directory established. Test suites will be populated in **Milestone 6**.

## Planned E2E Test Coverage
- Organization signup and user onboarding wizard flow.
- Multi-tenant data boundary verification (Tenant A vs Tenant B).
- CSV transaction upload, automated AI categorization review, and batch posting.
- Double-entry posting verification, reversal entry posting, and period locking rejection behavior.
